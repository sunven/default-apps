直接打开 [desktop-workflow-prototype.html](desktop-workflow-prototype.html)。数据、图标、CSS 和 JavaScript 均内嵌，双击即可运行；也可在项目根目录运行 `open frontend/src/prototypes/default-apps/desktop-workflow-prototype.html`。无需服务器或安装依赖，刷新／重置恢复内存起点。

## 比较方式

底部切换器同步 `?variant=A|B|C`，可重载回到同一方案。键盘左右箭头只在切换器内作用；它不是产品导航要求。

| 方案 | 滚动行为 | 观察点 |
| --- | --- | --- |
| A 双列表独立滚动（已选） | 应用列表和关联列表独立滚动；顶部入口、所选应用信息、筛选与请求状态固定 | 长列表中仍能看清所处应用及筛选范围 |
| B 右侧整片滚动 | 应用列表独立；右侧应用信息、筛选与关联列表一起滚动 | 右侧可见更多行，但筛选需滚回顶部 |
| C 内容随窗口滚动 | 右侧内容随页面滚动；左侧应用列表保持固定高度并独立滚动 | 窗口滚动更直接，顶部入口离开视野；请求状态仍固定 |

在底部选择情景并点击「载入情景」。演练按钮、模拟系统结果、状态 JSON 和底部切换器都是原型工具；成品不包含它们。详情使用可关闭对话框，不常驻第三列，为较小桌面窗口保留关联行空间。

## 数据与八个情景

[抽样说明](../../../../.scratch/default-apps-v1/assets/catalog-sample/README.md)和 [原始快照](../../../../.scratch/default-apps-v1/assets/catalog-sample/snapshot.json)记录 92 份实机应用；其中 24 份没有文稿／URL 声明。原型添加 2 份应用压力样本，共 94 份；目录共 951 个原始与模拟条目，尚未做 UTType 解析和扩展名归一化。原型的显示名翻译仅用于少数常用应用。

所有默认值、候选列表、提交、回调、回读、外部变更和旧请求恢复均为模拟。系统候选使用独立数据，不从声明支持推导；手动应用列表可以选到没有声明的应用。未知默认显示「未提供模拟值」，不会冒充实机“未设置”。原始扩展名条目明确未解析、禁用修改。原型不会读取或更改真实默认设置，不连接 Wails，也不持久化。

| 情景 | 可观察结果 |
| --- | --- |
| 长列表 / Xcode | 168 项实机原始声明；搜索“压力样本”可查看 181 项长名称样本 |
| 搜索无结果 | 应用选择和关联列表清空，提供清除与另外两个入口 |
| 应用无声明 | 计算器显示无声明空态，不沿用上个应用详情 |
| 同名副本与长路径 | 两份预览按版本与路径区分；详情显示完整路径 |
| 同扩展名的不同类型 | `.jpg` 展示 JPEG、独立压力类型及未解析的旧式扩展名；没有合并不同身份 |
| 已选应用消失 | 列表移除原副本，右侧保留消失提示；不自动替换同名副本 |
| 等待中切换 / 刷新 | PDF 请求跨视图保留；刷新会模拟外部 PDF 默认变化，查询匹配目标也不结束等待 |
| 重新打开后结果未知 | 当前默认等于旧目标时旧请求仍未知；再次选择先说明旧请求仍可能完成 |

## 已确认的搜索、选择与键盘规则

应用搜索匹配名称、版本、路径、bundle 元数据或声明。应用信息命中时列出该应用全部声明；仅声明命中时只展示匹配声明。右侧筛选进一步限制当前关联列表。文件类型／协议入口各自保存搜索、选中项，A 中也保存其列表滚动位置；刷新保留这些上下文。切换应用重置其关联选择到第一项，不改动已提交请求。

无结果时不保留无关旧详情。应用消失时保留原路径提示，关联列表清空；当前默认若仍指向原路径，另外显示目录中已找不到该副本，不能据此伪造新默认。清空搜索回到可见列表，不作为恢复修改的操作。

Tab / Shift-Tab 跨控件，应用列表每次只有一个 Tab 停靠点；关联列表停靠于当前行名称与可用动作。↑↓ / Home / End 只在当前列表移动并同步选择，不抢走其他控件方向键；搜索框 ↓ 进入结果。Enter 从应用进入关联列表，从关联名称打开详情。Escape 关闭顶层对话框并回到触发控件；在搜索框内清空该搜索，不撤回请求。⌘F 聚焦当前入口的主搜索，⌘1 / ⌘2 / ⌘3 切到应用／文件类型／协议。原生菜单与 WKWebView 中的快捷键仍需成品验证。

首版最小 **内容区域 1000×700** 已确认，原生标题栏高度另计。960×640 保留作为历史比较，正式窗口需核对逻辑像素与内容区域。仅针对 macOS 桌面，不做移动或平板布局。

## 请求与刷新

「设为此应用」或候选中的「设为默认」立即提交一项内存请求，没有暂存草稿、批量、恢复或停止等待。等待期间全局暂停新写入，浏览和查询可用；「模拟系统返回成功」只推进到待回读；「回读请求项」检查实际路径后才显示已确认或差异。跨视图顶部状态始终显示原关联项和目标路径。

演示的「刷新当前默认」会先切换模拟系统的 PDF 默认再查询，以便肉眼看清外部变更；正式刷新只查询，不执行这种切换。旧进程请求恢复不会自动写入；手动再次选择时先显示旧请求仍可能完成的说明，关闭说明不提交，点击明确提交才建立新请求。完整系统错误、退出和晚到场景仍以[修改语义决议](../../../../.scratch/default-apps-v1/issues/05-change-semantics-prototype.md)及[修改交互原型](change-semantics-README.md)为准。

## 验证与视觉评议

2026-11-05，命名浏览器会话 `default-apps-desktop-workflow`：通过真实 DOM 控件依次载入八个情景，检查空态、长列表、副本、扩展名歧义、消失和未定记录；实际按键检查搜索、列表移动、详情、Escape 返回焦点及三个入口各自保存筛选。验证待决时刷新即使匹配目标仍为 waiting，callback 后为待回读，回读后才 confirmed；旧请求说明关闭不提交，明确再次提交建立新请求并锁定候选。

[行为与尺寸记录](../../../../.taste-skill/desktop-workflow-checks.json)。1440×900、1280×800、1000×625 三种方案均 **0 FAIL / 1 WARN**；报告分别为 [A](../../../../.taste-skill/desktop-workflow-A/report.json)、[B](../../../../.taste-skill/desktop-workflow-B/report.json)、[C](../../../../.taste-skill/desktop-workflow-C/report.json)。检查器将 1000px 命名为 tablet，仅表示桌面窗口宽度。另检查 [1000×700 等待状态](../../../../.taste-skill/desktop-workflow-pending-1000.png)、[960×640 等待状态](../../../../.taste-skill/desktop-workflow-pending-960.png)与[长路径详情](../../../../.taste-skill/desktop-workflow-copy-detail.png)，横向溢出为 0，操作可滚动到达。

视觉沿用 Framed sheet，seed `1734816166`，macOS 系统字体、浅灰框架、白色内容；产品识别来自原有文件箭头标记与真实应用图标。关联行是最大区域，常用关联在顶部，当前默认和操作对齐。没有静态阴影或渐变；对话框和原型悬浮控制条的阴影用于覆盖层。三个宽度的首屏与分页拼图均已查看。唯一保留的 tiny-text WARN 来自大量 12px 路径、版本、类型标识和原型说明；主行名称与动作使用 13–14px。未重新抽取方向，没有移动布局。

[axe 结果](../../../../.taste-skill/desktop-workflow-a11y.json)：0 violations，1 类 incomplete（color-contrast），原因是滚动容器外的裁剪行无法自动确定背景；可见文字与背景在截图中复核。[详情对话框报告](../../../../.taste-skill/desktop-workflow-dialog-a11y.json)为 0 violations／0 incomplete；两份报告不可合并为整个原型 0 incomplete。没有将该结果视为完整可访问性验收，Wails 原生窗口、macOS 键盘设置及辅助功能仍需正式实现后验证。

项目没有 Git 仓库，以本地源码、原始抽样、截图和工单保留证据；未初始化仓库、未新增产品依赖、未编写原型测试套件，也没有实现正式产品。用户选择已记录在桌面决议，后续由验收工单汇总。

最终检查：前端 TypeScript 与生产构建通过；产物不包含桌面原型、抽样内容或模拟请求文案。36 个本地文档链接有效，源码 lint 为 0 FAIL / 0 WARN。屏幕阅读器状态节点固定到页面原点后，1000×700 文档高度恰为 700，无多余纵向页面滚动。
