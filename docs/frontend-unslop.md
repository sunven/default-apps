# macOS 前端 Unslop 记录

2026-11-18。范围为 `frontend/`，采用局部打磨模式；用户已确认方向。保留 Butter 主题、Outfit 字体、真实应用图标、页面结构和现有功能。

产品：为 Mac 的文件类型和链接选择默认打开应用。性格：准确、熟悉、稍带温度。视觉世界：Mac 的文件与应用目录。重点：真实应用图标，以及对齐、可读的关联行。标志性细节：当前默认应用旁的小勾。

原始审计发现：1280px 窗口中操作按钮换行，表格行从预期 60px 增至 93px；1000px 最小窗口的顶栏换行至 106px；列表、弹窗和批量流程存在 3、10、14、18px 的零散间距；顶栏操作、类型图标及“已是默认”控件都使用蓝色；控件图标存在 14、16、22px 多种尺寸；字标使用 650 字重、标题负字距、查询时间仅 11px；普通版本信息套有边框标签。

## 九轮处理

| 轮次 | 处理结果 |
| --- | --- |
| 间距 | 列表内边距改为 4px，弹窗、批量、拖入和更新区域使用已有 Astryx 间距变量。导航和顶栏采用 32px 控件，表格按钮采用同一高度、4px 内边距与间隔，常规行保持 60px |
| 颜色 | 保留主题颜色，通过已有语义变量降低界面的蓝色密度。顶栏辅助操作与文件类型图标用次要文本色；选中行用主题中性表面，左侧细线标明选择；批量目标边框恢复为中性边框 |
| 图标 | 继续使用既有 Lucide 图形，控件统一为 16px、1.5 描边。真实应用图标和产品标志保留各自的尺寸与材料 |
| 文案 | 检查后保留现有中文标签、关联说明、应用位置和确认文案。没有添加功能、宣传数字或样例内容 |
| 字体 | 字标、标题与列表主标签使用 500 字重，去掉标题负字距和副标题字距。查询时间、批量列表辅助信息及修改行状态提高到 12px，保留全局等宽数字 |
| 布局 | 保留左右独立滚动和既有列宽。通过控件尺寸与内边距解决按钮换行，并保留最小窗口的滚动条空间；1000×700 顶栏为 64px，三个浏览入口的表格均无水平溢出 |
| 细节 | “已是默认”使用可读的灰色勾选状态；版本信息成为普通辅助文字。应用行使用 8px 圆角，配合列表 4px 内边距；键盘焦点圈有明确边界 |
| 视觉 | 保留应用原有图标作为内容重点。没有新增装饰图片，没有使用图片生成服务，也没有图片提示词 |
| 动效 | 列表表面过渡使用主题的统一时间与曲线。移除入口中的通用营销动效样式，使键盘焦点圈立即出现；保留 Astryx 的弹窗和控件反馈 |

## 验证与产物

现有 React 测试：16 个文件、209 项通过。生产前端构建与 `wails3 task darwin:package` 通过，应用已重新打包并完成 ad-hoc 签名验证。`git diff --check` 通过。

最终 `npx --no-install astryx doctor --built dist`：20 项通过、0 失败、2 项警告。警告来自已有主题的外部字体加载无法由静态检查证明；浏览器确认 Outfit 已加载。此命令检查构建产物，不代表完整 JSX 静态规范审查。Vite 仍报告已有主 JavaScript 包超过 500kB；本次仅打磨界面，没有调整依赖或代码拆分。

浏览器在 1280×800 与 1000×700 检查页面。在最小尺寸下，应用、文件类型和 URL 协议页的页面及表格水平溢出均为 0，常规表格行均为 60px。详情弹窗与双项批量预览均无水平溢出；弹窗包含键盘焦点；ArrowDown 从 PDF 行移动到 JPEG 行而不打开详情；从批量预览返回后保留两项勾选。
