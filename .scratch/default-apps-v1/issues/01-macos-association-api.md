## Question

对于文件类型和 URL 协议，macOS 提供哪些公开接口来读取当前默认应用、列出可选应用和更改默认应用？能否从已安装应用反查声明支持的关联项，哪些信息无法完整枚举？

调查扩展名、文件类型标识、MIME、应用声明与实际默认关联之间的关系；说明类型继承、处理角色、未声明的关联、同一应用多份安装及默认浏览器/邮件应用等特殊情况。明确 API 的可用系统版本、弃用情况、授权或系统确认、返回值与回读能证明什么，并区分公开文档保证与尚需实机验证的行为。

使用 Apple 官方文档、公开头文件及官方源码等一手资料。结合当前 macOS 27.2 / arm64 的只读环境，提出首版可依赖的能力边界和未决问题。不要改变真实的系统默认设置。

## Answer

macOS 12 起可用 NSWorkspace 公开接口分别查询类型/协议默认应用和候选，并异步修改默认值；部分修改需系统用户确认。应用支持声明与当前默认是两种信息；扩展名与文件类型为多对多关系，不能仅按扩展名存储默认设置。所调查接口不能直接提供完整全系统目录，产品须决定目录来源和覆盖边界。

依据与只读样本见 [macOS 默认关联接口调查](../research/macos-association-api.md)。本机验证了 jpg 可解析为不同类型、具有不同默认应用，以及系统候选包含标准应用目录之外的副本。调查未改变真实默认关联；写入后的取消、未声明应用、刷新时机等行为尚未实测。

研究工单已解决，表示事实调查完成；目录、交互与技术路线仍由后续工单决策。
