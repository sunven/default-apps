# 03: 从已安装应用浏览关联

**What to build:** 用户启动后默认从已安装应用出发，选中具体应用副本即可查看它声明支持的关联和系统实际默认；扫描问题不会妨碍浏览其余可用结果。

**Blocked by:** [02: 常用文件类型与协议目录](02-common-association-catalog.md).

**Status:** resolved

- [x] 异步扫描已确认的系统、用户及系统内置应用三个常规目录，覆盖子目录；遇到应用包读取其声明后停止向包内普通递归，避免符号链接循环。（CAT-1）
- [x] 不可读位置、损坏声明和其他局部发现问题与可用结果一起展示，保留可用目录；扫描不阻塞主线程，也不修改默认或把扫描错误当成系统无默认。（CAT-1、QUERY-2）
- [x] 正式主入口为应用视角，保留文件类型与 URL 协议入口。选中应用显示名称、版本、路径和声明关联，逐项查询实际默认；无声明时呈现明确空态。（UI-1、QUERY-1）
- [x] 应用声明与常用种子按关联身份合并来源，常用项优先；同扩展名的不同类型分别呈现，未解析声明保持可辨认且不可写。（CAT-2）
- [x] 规范包位置相同的路径别名去重，同名或同 bundle ID 的不同安装保留各自名称、版本与完整路径；规范化遵守实际文件身份，不统一小写路径。（CAT-4）
- [x] 声明支持、系统候选和默认应用有各自来源；扫描范围外的系统候选与默认仍可查看和选中具体副本，不要求其先进入扫描结果。（CAT-4、QUERY-1）
- [x] 提供应用与关联的基本选择及详情路径，使本项可独立演示；复杂搜索、滚动和焦点交由 04，手动补充交由 05，刷新中的消失处理交由 07。
- [x] 以含嵌套目录、包内 helper、符号链接循环、坏声明及不可读位置的夹具验证扫描边界；在正式窗口进行真实只读扫描，记录规模、耗时和局部问题，并验证两份同名副本及目录外候选。

依据：[实施入口](../spec.md)、[目录与候选决议](../../default-apps-v1/issues/03-association-catalog.md#answer)、[架构方案](../../default-apps-v1/assets/architecture-proposal.md)、[验收矩阵](../../default-apps-v1/assets/acceptance-criteria.md#验收矩阵)。
