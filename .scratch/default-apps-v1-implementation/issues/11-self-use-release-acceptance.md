# 11: 自用成品与集成验收记录

**What to build:** 交付可运行的自用 macOS 应用，以及能逐项判断首版行为是否达到规格的验收记录。用户可完成浏览、手动补充、逐项修改与退出恢复，并清楚知道哪些特殊系统行为尚未观察。

**Blocked by:** [04: 完整桌面搜索与键盘浏览](04-desktop-search-keyboard.md), [10: 真实 URL 协议修改](10-native-url-scheme-change.md).

**Status:** ready-for-agent

- [ ] 交付在已选 macOS 27.2／Apple Silicon 环境运行的正式 `.app`，附可复现的构建与启动说明、构建身份、签名及实际工具版本。普通／开发产品身份和 macOS 13 构建下限一致，固定 Go 1.27.3、Wails 3.1.0 和现有前端锁文件。（BUILD-1）
- [ ] 核对生产产物展示正式功能，排除问候示例、原型参数入口、演练控制栏、压力数据和独立探针；测试替身通过独立测试环境使用。（BUILD-2）
- [ ] 汇总验收矩阵全部 25 个编号的证据、层级与状态，区分规则、界面、原生；各工单已有验证可在对应构建和未变更前提下复用，组合变化与未覆盖的集成场景补测。所有必需规则与核心原生流程通过，失败项不标为完成。
- [ ] 在正式窗口完成真实扫描、常用关联只读查询、目录外副本、文件／应用选择器及手动项跨启动保存；核对未解析、歧义、局部扫描问题和失败重查的呈现。（CAT-1、CAT-2、CAT-3、CAT-4、QUERY-1、QUERY-2、STORE-1）
- [ ] 组合 04 与后续请求／恢复界面，在 1000×700 实际内容区域验证双列表滚动、搜索、各入口会话状态、长等待条、完整键盘规则及新增对话框焦点；长路径、无声明和压力夹具不遮挡操作。（UI-1、UI-2、UI-3、UI-4）
- [ ] 提供正式应用的一项专用文件类型和一项专用协议真实成功证据，含明确提交、completion、规范目标路径匹配回读及手动新请求改回；失败、另一副本和回读差异按真实结果报告，不能以“尚未观察”替代两类真实成功。（WRITE-1、WRITE-4）
- [ ] 正式 Wails 壳内以可控适配器完成长等待、晚到结果、重复提交、前端重载、错误／回读失败、存储失败及事件竞态；三类退出入口、强制结束后的未定记录恢复、再次明确修改均须有集成证据。旧请求不自动重放，不以当前匹配补记旧成功。（WRITE-2、WRITE-3、WRITE-5、WRITE-6、SYNC-1、STORE-2、STORE-3、RECOVER-1、RECOVER-2、QUIT-1）
- [ ] 对专用关联进行真实系统取消／拒绝、真实请求待决退出重开、同 ID 多副本及未声明应用的针对性尝试，记录触发条件、人工按钮选择和结果。只有已确认门槛允许的系统触发机会不足情景可记为“尚未观察”，并列明自用限制；真实崩溃、重复 setter、假成功、丢记录或不能重查必须修复。
- [ ] 每轮证据记录日期、系统／架构、构建与工具版本、关联身份、目标完整路径、提交前默认、用户动作、系统提示与实际选择、NSError 字段、各次回读、退出／重开方式和清理结果；状态使用“通过”“失败”“尚未执行”“尚未观察”，明确原生或替身。
- [ ] 核对实验前后日常默认快照，日常 PDF、浏览器和邮件保持只读。只注销本次专用应用，不重置 Launch Services 全库；若回读仍指向夹具，记录具体残留并处理清理问题后再签收，不声称恢复为从未设置。
- [ ] 完成报告说明构建下限不等于全部 macOS 13+ 已验证，列出仍缺少的原生特殊观察及适用范围；商业分发、公证、更新、商店、其他平台和 Intel／universal 保持在首版范围之外。
