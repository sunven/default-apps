# 04: 完整桌面搜索与键盘浏览

**What to build:** 用户在真实应用与关联目录中，可以用搜索、鼠标和键盘完成浏览；长列表、长路径和最小窗口下仍能访问全部内容，并在切换入口后继续原来的浏览位置。

**Blocked by:** [03: 从已安装应用浏览关联](03-app-first-discovery.md).

**Status:** resolved

- [x] 采用已选 A 双列表独立滚动，浏览入口、所选应用信息与搜索／筛选保持可见；详情使用可关闭对话框。最小内容区域为 1000×700，原生标题栏另计，无横向溢出或不可达动作。（UI-2）
- [x] 应用搜索覆盖名称、版本、路径、bundle 元数据与声明关联；命中应用信息时显示全部声明，仅声明命中时显示匹配声明并说明范围。右侧独立筛选进一步缩小关联列表，常用关联优先。（UI-1）
- [x] 无搜索结果时清空无关旧详情；无声明时显示空态并保留其他浏览入口。相同名称副本、长路径与同扩展名的不同类型可分别辨认，详情提供完整路径。（UI-1）
- [x] 各浏览入口保留本次会话的搜索、选中项和滚动位置，身份采用关联与副本身份；切换应用从该应用首个可见关联开始，不把选择当成修改草稿。（UI-4）
- [x] Tab／Shift-Tab 跨控件；应用列表以当前项作为 Tab 停靠点，关联列表可到当前名称与可用动作；↑↓／Home／End 只操作当前列表，搜索框 ↓ 进入结果，不抢占其他控件或输入法按键。（UI-3）
- [x] Enter 从应用进入关联列表，从关联名称打开详情；没有关联时进入筛选或空态可用入口。Escape 关闭顶层对话框并恢复合理焦点，焦点在搜索框时只清空该搜索。（UI-3）
- [x] ⌘F 聚焦当前主搜索，⌘1／2／3 切换应用、文件类型、协议；核对 Wails 菜单、WebView 和 macOS 键盘设置中的实际行为。（UI-3）
- [x] 用正式浏览界面验证真实目录规模，并以独立测试夹具覆盖长名称、重复副本、无声明及 1000 级关联；记录搜索、空态、双列表滚动、键盘和焦点返回的证据，测试夹具不进入生产产物。（UI-1、UI-2、UI-3、BUILD-2）
